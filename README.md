# ProjectWar

A strategy/RTS game prototype developed with **Unreal Engine 5**. 

This project features custom camera controls, unit selection mechanics, AI controllers, and basic vehicle/character interactions. It is built using a mix of C++ and Blueprints.

## 🌟 Features (In Development)
* **Custom Camera System**: Strategy-style top-down camera with panning and zooming capabilities.
* **Unit Management**: Select and send units (characters and vehicles/tanks) across the map.
* **AI Controllers**: Basic AI logic for enemy units and pathfinding.
* **Vehicles and Structures**: Includes functional tanks, test buildings (e.g., 5-story building), and trenches.

## 🛠️ Prerequisites
* **Unreal Engine 5.x** (Ensure you have the correct version installed via the Epic Games Launcher).
* **Visual Studio 2022** or **Rider** with C++ game development workloads installed.

## 🎮 Controls
* **Left Mouse Button (LMB)**: Select actors / units.
* **Mouse Movement / Edges**: Pan the camera.
* **Shift / Ctrl**: Multi-selection modifiers.
* **Right Mouse Button (RMB)**: Send unit / issue command.

*(Note: Controls are actively being configured and may change during development.)*
